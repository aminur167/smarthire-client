# SmartHire Client — AI-Powered Recruitment Dashboard

> Modern React frontend for the SmartHire recruitment platform.

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS 3.4 |
| Routing | React Router v6 |
| HTTP | Axios |
| Icons | Lucide React |
| Charts | Recharts |
| Toasts | React Hot Toast |
| File Upload | React Dropzone |

## ⚡ Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 📁 Structure

```
src/
├── api/          # Axios API layer
├── components/   # Reusable UI components
│   ├── auth/     # Login, Register forms
│   ├── common/   # Button, Card, Input, Modal, Table...
│   ├── dashboard/# Status cards, Jobs overview, Interviews
│   ├── jobs/     # Job cards, forms, details
│   ├── candidates/ # Profiles, CV upload
│   ├── interviews/ # Interview cards, scheduling
│   └── layout/   # Sidebar, Navbar, Layout
├── context/      # Auth context
├── hooks/        # Custom hooks
├── pages/        # Route pages
└── utils/        # Helpers, constants
```
